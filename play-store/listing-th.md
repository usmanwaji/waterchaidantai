# ข้อความสำหรับ Play Store listing — ฉบับร่าง

ตัวเลขความยาวด้านล่างนับด้วย Python `len()` ไม่ใช่ตัวนับจริงของ Play Console
(อาจนับอักขระประกอบ/วรรณยุกต์ต่างวิธีกันบ้าง) **อ่านทวนและวางในช่องจริงของ
Play Console ก่อนกดส่ง เพื่อให้เห็นตัวนับที่ถูกต้องและตรวจการตัดคำ**

---

## คำอธิบายสั้น (Short description — จำกัด 80 ตัวอักษร)

```
เฝ้าระวังน้ำท่วม จ.นราธิวาส ระดับน้ำ ฝนพยากรณ์ ศูนย์พักพิง แจ้งเตือน Telegram
```
(77 ตัวอักษร)

## คำอธิบายเต็ม (Full description — จำกัด 4000 ตัวอักษร)

```
naraflood รวมข้อมูลสถานการณ์น้ำท่วมจังหวัดนราธิวาสไว้ในที่เดียว สำหรับประชาชน
และเจ้าหน้าที่ที่ต้องติดตามสถานการณ์อย่างรวดเร็วในวันที่ฝนตกหนัก

สิ่งที่ทำได้ในแอป:
• ระดับน้ำสถานีวัดสำคัญแบบเรียลไทม์ พร้อมสถานะเทียบกับระดับตลิ่ง
• พยากรณ์อากาศ 24 ชั่วโมงและ 7 วันข้างหน้า รายอำเภอ (แบบจำลอง Open-Meteo)
• แผนที่คาดการณ์ปริมาณฝนรายอำเภอจากกรมอุตุนิยมวิทยา พร้อมตัวเลขบนแผนที่
• "เช็คพื้นที่ฉัน" — เลือกอำเภอหรือใช้ตำแหน่งปัจจุบัน ดูระดับความเสี่ยงและ
  คำแนะนำได้ในหน้าเดียว
• รายชื่อศูนย์พักพิงที่เปิดรับใกล้ที่สุด
• สมัครรับแจ้งเตือนผ่าน Telegram ได้ทันทีในแชท ไม่ต้องรอเจ้าหน้าที่อนุมัติ
  พิมพ์ /start แล้วเลือกระดับความไวที่ต้องการ

แหล่งข้อมูล: กรมอุตุนิยมวิทยา, thaiwater.net (สสน.), สำนักงานทรัพยากรน้ำ
แห่งชาติ (สทนช.), กรมชลประทาน, Open-Meteo

จัดทำและดูแลโดยอาสาสมัครอิสระ ไม่ใช่แอปทางการของหน่วยงานราชการ ใช้ประกอบ
การตัดสินใจร่วมกับประกาศทางการของหน่วยงานที่เกี่ยวข้องเสมอ

นโยบายความเป็นส่วนตัว: https://naraflood.com/privacy.html
```

## หมวดหมู่ที่แนะนำ

**สภาพอากาศ (Weather)** หรือ **เครื่องมือ (Tools)** — ไม่ใช่ "ข่าว" หรือ
"รัฐบาล" เพราะแอปนี้ไม่ใช่ของหน่วยงานราชการ (ดูหมายเหตุด้านบน)

## ภาพหน้าจอ

อยู่ในโฟลเดอร์นี้ (`screenshot-1-home.png` ฯลฯ) — ถ่ายจากเบราว์เซอร์จริงที่
ความกว้าง 412px (ขนาดจอมือถือทั่วไป) โดยจำลองข้อมูล API เพราะตอนถ่ายไม่มี
เครือข่ายเข้าถึงปลายทางจริง **ควรถ่ายซ้ำจากเว็บจริงหรือแอปที่ build แล้วก่อน
ส่งขึ้น Play Store** เพื่อให้เห็นข้อมูลปัจจุบันจริง ภาพชุดนี้ใช้เป็นตัวอย่าง
sizing/layout ที่ผ่านเกณฑ์ของ Play Console แล้ว (412×800, สัดส่วน ~1.94:1
อยู่ในเกณฑ์ไม่เกิน 2:1 ที่ Play Console กำหนด)
