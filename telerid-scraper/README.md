# telerid-scraper — ดึงภาพกล้อง+ระดับน้ำ โทรมาตร ชป. (5 จังหวัดใต้)

ดึงภาพกล้อง CCTV + ระดับน้ำ ของสถานีโทรมาตร [telerid.rid.go.th](https://telerid.rid.go.th/)
ใน **สตูล · สงขลา · ปัตตานี · ยะลา · นราธิวาส** แล้วส่งภาพขึ้นสาขา `cam` ให้ dashboard แสดง

> ⚠️ **ต้องรันบนคอมที่ IP ไทย** — telerid บล็อก IP เซิร์ฟเวอร์ต่างประเทศ (GitHub Actions/Cloudflare ใช้ไม่ได้)
> จึงต้องรันบนคอมของท่านเอง (ที่ออฟฟิศ/ที่บ้าน ซึ่งเป็นเน็ตไทย)

---

## ตั้งค่าครั้งแรก (ทำครั้งเดียว ~10 นาที)

### 1) ลง Node.js
- โหลดจาก https://nodejs.org (เลือกปุ่ม **LTS**) → ติดตั้งแบบกด Next ไปเรื่อย ๆ จนเสร็จ

### 2) สร้าง "กุญแจ" ให้สคริปต์ส่งภาพขึ้น GitHub ได้ (Personal Access Token)
1. เข้า https://github.com/settings/tokens?type=beta → กด **Generate new token**
2. ตั้งชื่ออะไรก็ได้ เช่น `telerid`
3. **Repository access** → เลือก **Only select repositories** → เลือก `waterchaidantai`
4. **Permissions → Repository permissions → Contents** → เลือก **Read and write**
5. กด **Generate token** → **คัดลอกโทเคน** (ขึ้นต้น `github_pat_...`) เก็บไว้ (โชว์ครั้งเดียว)

### 3) บอกคอมให้จำโทเคน (ทำครั้งเดียว)
- เปิด **Command Prompt** (พิมพ์ `cmd` ที่ช่องค้นหา Windows)
- พิมพ์บรรทัดนี้ (แทนที่ `วางโทเคนตรงนี้` ด้วยโทเคนจากข้อ 2):
  ```
  setx GH_TOKEN "วางโทเคนตรงนี้"
  ```
- กด Enter → **ปิดหน้าต่าง Command Prompt** (สำคัญ: ต้องปิด-เปิดใหม่ค่าถึงจะมีผล)

## วิธีใช้งาน (ทุกครั้ง)

ไปที่โฟลเดอร์ `telerid-scraper` แล้ว **ดับเบิลคลิกไฟล์ `run-local.bat`**

- ครั้งแรกจะติดตั้งของที่จำเป็นก่อน (รอ 2-3 นาที) ครั้งต่อไปจะเร็ว
- มันจะ: เปิด telerid → ดึงภาพกล้องทุกสถานี → ส่งขึ้น GitHub สาขา `cam`
- เสร็จแล้วเปิดเว็บหน้า **สถานการณ์** → เปิดชั้น **โทรมาตร ชป.** → คลิกหมุด ▲ เห็นภาพเลย

## โหมดสด (แนะนำ) — หน้าแผนที่อัปเดตภายในไม่กี่นาที

สถานีโทรมาตร ชป. ส่งค่าทุก **15 นาที** (ภาพกล้องตามรอบของสถานี) โหมดสดจะเปิด Chromium ค้างไว้
แล้วเช็ก telerid **ทุก 2 นาที** ส่งขึ้น GitHub **เฉพาะตอนค่าเปลี่ยน** (อัปโหลดแค่ไฟล์ที่เปลี่ยน)
หน้าแผนที่เช็กไฟล์ใหม่ทุก 2 นาที → ค่าใหม่ขึ้นเว็บภายในราว **2-5 นาที** หลังสถานีส่งค่า
(แบบเดิมที่รัน `run-auto.bat` ทุก 15-30 นาที ช้าได้ถึง 30-60 นาที)

- **ลองดูก่อน:** ดับเบิลคลิก `run-live.bat` → เปิดหน้าต่างทิ้งไว้ (ปิดหน้าต่าง = หยุด)
- **ดู log:** เปิดไฟล์ `telerid-live.log` — ทุกรอบจะมี 1 บรรทัด เช่น `ส่งขึ้นแล้ว · มีข้อมูล 10/35 ...` หรือ `ไม่มีค่าใหม่`
- **ถ้า telerid ล่ม/ดึงไม่ได้:** จะไม่ส่งข้อมูลว่างขึ้นไปทับ และเว้นระยะยิงนานขึ้นเอง (สูงสุด 15 นาที)
- **เปลี่ยนรอบ:** `setx WATCH_MIN 3` (นาที, ค่าเริ่มต้น 2)

### ตั้งค่าทีเดียวจบ (ง่ายสุด) — `setup-live`

เปิดโฟลเดอร์ `telerid-scraper` → คลิกช่อง address bar ของ Explorer → พิมพ์ `powershell` กด Enter → วางบรรทัดนี้แล้วกด Enter
```
irm https://raw.githubusercontent.com/usmanwaji/waterchaidantai/main/telerid-scraper/setup-live.ps1 | iex
```
(หรือดับเบิลคลิก `setup-live.bat` ถ้ามีไฟล์นี้ในโฟลเดอร์แล้ว) สคริปต์จะทำให้ครบ:
โหลดไฟล์ล่าสุด → เช็ก/ติดตั้ง Node.js → ติดตั้ง Chromium → เช็กและบันทึก GH_TOKEN →
ปิดงานเดิม (`run-hidden.vbs`/`run-auto.bat`) → สร้างงาน `telerid live` (ตอนล็อกอิน + ทุก 15 นาที) →
เริ่มโหมดสดทันทีและรอผลรอบแรก → ถามว่าจะตั้งไม่ให้คอม Sleep ไหม · รันซ้ำได้ทุกเมื่อ (อัปเดตโค้ด + รีสตาร์ทให้)

### ให้รันเองตลอด (Task Scheduler) — ถ้าอยากตั้งเอง

1. เปิด **Task Scheduler** → **Create Basic Task…** ตั้งชื่อ `telerid live`
2. Trigger: **When I log on**
3. Action: **Start a program** → เลือกไฟล์ `run-live-hidden.vbs` ในโฟลเดอร์นี้
4. เปิด Properties ของงานนี้ → แท็บ **Triggers** → Edit → ติ๊ก **Repeat task every: 15 minutes**, for a duration of: **Indefinitely**
   (เรียกซ้ำได้ไม่ซ้อนกัน: ถ้ารันอยู่แล้วตัวใหม่ปิดตัวเองทันที ถ้าล่มหรือรีสตาร์ทคอม รอบถัดไปเปิดให้ใหม่)
5. ถ้าเคยตั้งงานเดิมที่เรียก `run-hidden.vbs` / `run-auto.bat` ไว้ → **ปิด (Disable) งานเดิม** จะได้ไม่ดึงซ้ำสองทาง

> คอมต้องเปิดและต่อเน็ตไทยอยู่ (ตั้ง Power Options ไม่ให้ Sleep) — ถ้าอยากให้นิ่งกว่านี้ ใช้ VPS ในไทยหรือมินิพีซีที่เปิดทิ้งไว้ก็ได้ ใช้สคริปต์ชุดเดียวกัน

## ให้มันดึงเองอัตโนมัติแบบเดิม (รอบละครั้ง)

ใช้ **Task Scheduler** ของ Windows ตั้งให้เปิด `run-hidden.vbs` (เรียก `run-auto.bat`) ทุก 15-30 นาที
(คอมต้องเปิดอยู่ตอนมันรัน) — ใช้แทนโหมดสดได้ ถ้าไม่อยากให้ Chromium เปิดค้าง

## ถ้าดึงภาพได้ 0 ตัว

เปิดไฟล์ `telerid-cam/stations.json` ดูค่า `withImage` และ `tokenCaptured`
พร้อมไฟล์ `telerid-cam/_discovery.json` → ส่ง 2 ไฟล์นี้ให้ผมปรับสคริปต์

**ถ้าจำเป็นต้องล็อกอิน RID** (anonymous ไม่ได้จริง ๆ): เปิด Command Prompt ตั้งค่าเพิ่ม
```
setx RID_USER "ชื่อผู้ใช้ RID"
setx RID_PASS "รหัสผ่าน RID"
```
แล้วปิด-เปิดใหม่ ค่อยดับเบิลคลิก `run-local.bat` อีกครั้ง
(รหัสอยู่ในเครื่องท่านเท่านั้น ไม่ถูกส่งขึ้นเว็บ)
