ข้อมูลที่เก็บ

แต่ละแถวคือข้อมูลคนละชุด ไม่ได้เก็บทุกอย่างจากทุกคน — เก็บเฉพาะส่วนที่ตรงกับสิ่งที่คุณใช้งาน

ใช้ฟีเจอร์ไหนเก็บอะไรใครเห็นได้
เปิดดูเว็บทั่วไป จำนวนครั้งเข้าชมต่อหน้า/วัน + หมวดอุปกรณ์/ที่มา/ช่วงเวลา (ตัวเลขสรุปรวม) ไม่ระบุตัวบุคคล
ไม่มีคุกกี้ ไม่เก็บหมายเลขไอพี ไม่มีรหัสประจำตัว
สมัครแจ้งเตือนผ่านบอท Telegram Telegram chat id ของคุณ + ระดับที่เลือก (เฝ้าระวัง/ล้นตลิ่ง) เจ้าหน้าที่ที่ได้รับอนุมัติ เท่านั้น (ผ่านหน้า "จัดการกติกาแจ้งเตือน")
เข้าสู่ระบบด้วย Google (สมาชิก/เจ้าหน้าที่) อีเมล ชื่อ เบอร์โทร (ถ้ากรอก) จาก Google — ใช้ยืนยันตัวตนและอนุมัติสิทธิ์เข้าใช้ระบบภายใน ผู้ดูแลระบบ เท่านั้น
แจ้งจุดน้ำท่วมถนน (เจ้าหน้าที่/สมาชิกที่อนุมัติแล้ว) ชื่อและเบอร์โทรผู้รายงาน + ตำแหน่ง/ความลึกน้ำ สาธารณะ — แสดงบนหน้าเส้นทาง (route.html) ให้ทุกคนเห็นชื่อ-เบอร์ผู้รายงานได้ เพื่อให้ติดต่อยืนยันสถานการณ์ได้จริง
ทะเบียนกลุ่มเปราะบาง (เจ้าหน้าที่จังหวัด) ชื่อ ที่อยู่ถึงระดับหมู่บ้าน ประเภทความเปราะบาง (เช่น ผู้ป่วยติดเตียง/พิการ/ตั้งครรภ์) ความช่วยเหลือที่ต้องการ เบอร์ติดต่อ เจ้าหน้าที่ผู้ดูแลจังหวัดนั้นเท่านั้น
เป็นข้อมูลอ่อนไหวตาม PDPA — ไม่เปิดเผยต่อสาธารณะ
บันทึกเหตุการณ์ / คำขอทรัพยากรกู้ภัย (ปฏิบัติการภายใน) รายละเอียดเหตุการณ์ หน่วยงานที่ขอ เบอร์ติดต่อ (ถ้ามี) ผู้ที่ล็อกอินเข้าระบบ (ไม่จำเป็นต้องเป็นสมาชิกที่อนุมัติแล้ว)

ตัวอย่าง API สาธารณะที่เว็บดึงมาแสดง (กรมอุตุฯ, thaiwater.net, Open-Meteo ฯลฯ) ไม่มีการส่งข้อมูลส่วนตัวของคุณออกไปหาผู้ให้บริการเหล่านี้ — เป็นการดึงข้อมูลพยากรณ์/ระดับน้ำมาแสดงเท่านั้น

บริการภายนอกที่เกี่ยวข้อง

  • Supabase — ฐานข้อมูลและระบบยืนยันตัวตน (เก็บทุกอย่างในตารางด้านบน)
  • Telegram Bot API — ส่งข้อความแจ้งเตือนไปยัง chat id ที่คุณสมัครไว้
  • Google Sign-In — ใช้เฉพาะตอนเจ้าหน้าที่/สมาชิกเข้าสู่ระบบจัดการหลังบ้าน ผู้เยี่ยมชมทั่วไปไม่ต้องล็อกอิน
  • Cloudflare Workers — พร็อกซีเรียก API สาธารณะบางตัวที่ไม่เปิด CORS ให้เว็บ ไม่เก็บข้อมูลผู้ใช้เพิ่มเติม

สิทธิ์ของคุณ

  • ยกเลิกแจ้งเตือน Telegram: พิมพ์ /stop ในบอทได้ทันที — หยุดส่งข้อความทันที (แถวข้อมูลเดิมจะถูก "ปิดใช้งาน" ไว้ในฐานข้อมูล ไม่ได้ลบทิ้งทันทีเพื่อรักษาประวัติการแจ้งเตือน หากต้องการให้ลบข้อมูลออกจริง ติดต่ออีเมลด้านล่าง)
  • ขอดู/แก้ไข/ลบข้อมูลของคุณ: อีเมลหาผู้ดูแล พร้อมระบุว่าเป็นข้อมูลชุดไหน (เช่น Telegram chat id, บัญชี Google, รายงานน้ำท่วมที่เคยแจ้ง)
  • บัญชีเจ้าหน้าที่/สมาชิก: ผู้ดูแลระบบลบบัญชีให้ได้ตามคำขอ
