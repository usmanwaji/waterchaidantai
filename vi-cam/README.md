# vi-cam — ภาพนิ่งกล้อง CCTV เทศบาลเมืองนราธิวาสบนหน้า /map

จับภาพกล้องจากโปรแกรม **VI MonitorPlus** ที่เปิดค้างไว้บนคอมเครื่องนี้ **ทุก 20 นาที**
แล้วส่งขึ้นสาขา `vicam` ของ repo ให้หน้าแผนที่ชั้น **CCTV เทศบาล** แสดง

> ทำไมต้องจับจากหน้าจอ: กล้องอยู่ IP ภายในของเทศบาล (192.168.28.x) และ VI ใช้โปรโตคอลของตัวเอง
> เว็บและสคริปต์ดึงภาพจากกล้องตรง ๆ ไม่ได้ ถ้าวันหนึ่งเทศบาลให้ URL ภาพนิ่งของกล้องที่เข้าถึงจากภายนอกได้
> ให้เปลี่ยนไปดึงจาก URL นั้นแทน (เสถียรกว่า ไม่ต้องเปิดโปรแกรมค้าง)

ตอนนี้มีกล้องเดียว: **(จุดที่ 7-2) ตลาดน้ำยะกัง - ลานจอดรถ** · ชื่อและพิกัดแก้ได้ใน `cams.json`


## การอนุญาต

ภาพมาจากบัญชี `police` ของระบบกล้องเทศบาลเมืองนราธิวาส เทศบาลอนุญาตให้เผยแพร่บนเว็บแล้ว (2026-11-23)
ภาพบนสาขา `vicam` ใครก็เปิดดูได้ · เพิ่มกล้องตัวอื่นต้องขออนุญาตเป็นรายกล้อง

## สิ่งที่ต้องเปิดค้างไว้

1. เปิด **VI MonitorPlus** แล้วเลือก Connection Type เป็น **Multiple Servers** (ห้ามใช้ Primary Server: จะวิ่งไปหา IP ภายในแล้วไม่มีภาพ)
2. เปิดกล้องจุดที่ 7-2 ในแท็บของมันเอง แบบ **1 กล้องต่อแท็บ**
3. **ห้ามย่อหน้าต่าง** (มีหน้าต่างอื่นบังได้ สคริปต์จะยก VI ขึ้นมาจับภาพแวบเดียวแล้ววางกลับ)
4. คอม **ห้าม Sleep และห้ามล็อกหน้าจอ**: Windows จับภาพหน้าจอที่ล็อกอยู่ไม่ได้

ถ้าไม่เข้าเงื่อนไข (ภาพดำ/กล้องหลุด/ไม่ได้เปิดโปรแกรม) สคริปต์จะไม่ส่งอะไรขึ้นไป ภาพเดิมบนเว็บยังอยู่
และหน้าแผนที่ขึ้นป้าย "ภาพเก่า" เมื่อภาพเกิน 1 ชั่วโมง

## ตั้งค่าครั้งแรก

ใช้ Node.js และ `GH_TOKEN` ตัวเดียวกับ `telerid-scraper` (ดู README ในโฟลเดอร์นั้น)

- **ลองรัน 1 รอบ:** ดับเบิลคลิก `run.bat` แล้วดู `vi-cam.log`
- **ตั้งให้รันเองทุก 20 นาที:** เปิด PowerShell ในโฟลเดอร์นี้แล้วรัน `powershell -ExecutionPolicy Bypass -File setup-task.ps1`
- **หยุด:** `Unregister-ScheduledTask vi-cam`

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `cams.json` | ชื่อ/พิกัดกล้อง |
| `capture.ps1` | จับภาพกรอบวิดีโอใน VI → `out/<id>.jpg` + `out/cams.json` (exit 2 = ไม่มีภาพ) |
| `run.bat` | capture แล้วส่ง `out/` ขึ้นสาขา `vicam` ด้วย `../telerid-scraper/publish-github.mjs` |
| `run-hidden.vbs` | เรียก `run.bat` แบบไม่มีหน้าต่าง (ใช้กับ Task Scheduler) |
| `setup-task.ps1` | ตั้งงาน `vi-cam` ใน Task Scheduler |

ใช้สาขา `vicam` แยกจาก `cam` เพราะ publish แต่ละรอบสร้างสาขาใหม่จากไฟล์ในโฟลเดอร์ของตัวเองอย่างเดียว
ถ้าใช้ร่วมกัน ภาพของอีกงานจะหายทุกรอบ
